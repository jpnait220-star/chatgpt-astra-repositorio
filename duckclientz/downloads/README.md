A versão 1.5.28-beta.1 inclui JARs para Minecraft 1.20.1, 1.21.1, 1.21.4 e 1.21.11, usando Fabric.

Extraia o ZIP, retire o DuckClientZ antigo da pasta `mods` e instale **apenas o JAR correspondente à sua versão**, com Fabric API compatível. Não instale os quatro juntos.

As quatro versões iniciaram no Minecraft real e os 13 testes automatizados passaram. A beta ainda precisa de validação com seu conjunto de mods e de todas as opções visuais descritas no relatório.

O arquivo `.zip.sha256` permite verificar a integridade do download. O banner está no formato PNG, com proporção 3:1.

Para salvar o banner, baixe o ZIP e extraia `DuckClientZ-banner.png`. A imagem mantém a resolução original.
